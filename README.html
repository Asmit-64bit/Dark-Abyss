1. Executive Summary & Overview

Dark Abyss is an immersive pedagogical escape room designed to test real-world computer science fundamentals through psychological tension. Players explore an atmospheric underground laboratory ("Schrödinger's Abyss"), inspect physics-driven terminal props, solve algorithmic decryption tasks in an integrated code execution REPL sandbox, and regulate heart-rate telemetry while surviving pursuit by an anomaly entity (Sadako).

The game dynamically scales challenge difficulty across five standardized academic computer science domains in real time, factoring in code syntax errors, solve velocity, and hint reliance.

2. Key Innovations & Technical Features

AI Dynamic Puzzle Engine

Instant inference powered by Groq (openai/gpt-oss-120b & llama-3.3-70b-versatile). Dynamically generates unique contextual escape puzzles tailored to operator performance with sub-second response times.

6-Key Failover Rotator Pool

Multi-key round-robin management across 6 independent Groq keys. Automatically recovers from 429 TPM/RPM rate limits by hot-swapping active keys with zero player disruption.

Solo Solve Scoring & Telemetry

+25% score multiplier awarded for unassisted independent solves. Awards precision bonuses for zero syntax errors, sub-45s speed records, and high cognitive sanity preservation (≥ 80%).

Dual-Mode Cloud Leaderboard

Real-time player standings powered by Supabase with automatic direct REST API fallback for static hostings (Vercel/Netlify). Ranked by Top Score, Solo Purists, and Sanity Masters.

Full Mobile & Touch Controls

Dual touch controls featuring a virtual movement joystick, touch swipe camera controls, and dedicated HUD interaction triggers optimized for mobile and tablet landscape.

Psychological Sanity System

Dynamic sanity gauge (0–100) tied to a procedural Web Audio heartbeat synthesizer (72–152 BPM), triggering camera grain, chromatic aberration, and subliminal apparitions.

5. Architecture & Technology Stack

  • Client Architecture: Vite 8, React 19, TypeScript, Zustand global store (gameStore & authStore).
  • 3D Graphics & Physics: Three.js, React Three Fiber (R3F), Drei helper library, Rapier Physics engine.
  • AI Infrastructure: Groq Cloud API with automated 6-key rotational failover and JSON schema enforcement.
  • Cloud Database & Storage: Supabase PostgreSQL (custom profiles table, RLS security policies, and generated_questions database).
  • Deployment: Continuous deployment on Vercel with zero-backend direct REST API client fallbacks.

6. Quick Start & Setup Guide

# 1. Clone the repository
git clone https://github.com/Asmit-64bit/Dark-Abyss.git
cd Dark-Abyss

# 2. Install dependencies
npm install

# 3. Configure environment variables (.env)
PUBLIC_SUPABASE_URL=https://your-project.supabase.co
PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
GROQ_MODEL=openai/gpt-oss-120b
GROQ_API_KEY=gsk_...

# 4. Run local development server
npm run dev

# 5. Build for production
npm run build
